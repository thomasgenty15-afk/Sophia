**Skills / Operations / Tools**
- track_progress_plan_item: 2 exécutions correctes (T3 completed, T14 missed), mapping d'item et outcome exacts, jamais d'executor appelé directement (ledger requested→allowed→committed).
- create_one_shot_reminder: T8 correct, heure/TZ justes (20:00Z=22:00 Paris), one-shot.

**Memory / Effets durables**
- Intention mémoire T6 capturée. Vérif: `trigger-memorizer-daily` déclenché en fin de run → **skipped/no_unprocessed_messages** car les 15 messages user étaient déjà `memory_message_processing = primary/completed` (extraction **in-turn/async**). `memory_items` = 12 items, contenus exacts (week-end, déclencheur rentrée, mot de bascule, rappel 22h, préférence « droit au but », solitude, reports d'action…).

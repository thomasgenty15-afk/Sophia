  vérification) + gate d'admission de l'EffectLedger.
- Meilleure correction: l'intake ne doit pas requêter de track quand le tour est une
  vérification/recap sans nouveau report (et doit honorer « pas re-cocher »).
  L'idempotence reste un filet, pas la seule barrière. Même famille que r2 T9
  (BF-INTAKE-02) — le faux positif d'intent persiste sur un autre type de tour.
- Pourquoi ce n'est pas un patch local: c'est un faux positif de classification
  d'intention réutilisable partout, pas un wording ; corriger la phrase masquerait
  l'émission parasite.
